# discord-refresh-ui-improvements-helper

Helper code meant to be used with the following theme https://github.com/LinkTheDot/discord-refresh-ui-improvements

Removes the gradient if you are using a custom nitro theme (because, for some reason, they made it so the gradient is part of the scroller class when using a nitro theme...)

Requires a custom installation of Vencord to use (https://docs.vencord.dev/installing/)
